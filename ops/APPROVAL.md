# Правило публикаций «Бизнес на ИИ»

**Ничего не выходит без одобрения Гвидона в Telegram.** Это касается любой сессии Claude,
которая готовит контент: видео (TikTok, YouTube, Instagram через Metricool) и посты в канал @bizness_na_ii.
Одобрение в чате Claude больше не считается: превью с кнопками уходит в Telegram.

Отправка — от бота @biznes_na_ii_bot (Composio Telegram), `chat_id` Гвидона: `5094436756`.

## Пост в канал

1. Пришли превью ровно в том виде, в каком пост выйдет: `TELEGRAM_SEND_PHOTO` (картинка + подпись HTML ≤ 1024 знаков),
   `TELEGRAM_SEND_MESSAGE` (текст ≤ 4096) или `TELEGRAM_SEND_POLL`.
2. Ответом на него — сообщение с кнопками (`reply_to_message_id` = id превью):
   - `✅ Да` → `sp:y:<id превью>:<unix-время публикации>` (`0` — сразу)
   - `❌ Нет` → `sp:n:<id превью>`
   - `✏️ Изменить` → `sp:e:<id превью>`
3. Дальше бот всё делает сам: после «Да» копирует превью в канал в указанное время, после «Изменить» собирает правку.
   **Не публикуй в канал напрямую и не ставь отложенных задач на прямую публикацию.**

## Видео

1. Создай посты в Metricool с `draft: true` на нужное время (по одному на сеть).
2. Пришли видео-превью: `TELEGRAM_SEND_DOCUMENT` с публичной ссылкой ≤ 20 МБ
   (при необходимости сожми ffmpeg в `preview/`). В подписи: сети, время, подписи к роликам.
3. Кнопки — прямо на превью (`reply_markup`), id постов Metricool через дефис:
   `sv:y:<id1-id2-id3>` · `sv:n:<id1-id2-id3>` · `sv:e:<id1-id2-id3>` (callback ≤ 64 байт).
4. Решение приходит задачей (см. ниже). «ОДОБРЕНО» → перевести черновики в `draft: false`.
   «ОТКЛОНЕНО» → оставить черновиками (если пост уже был в расписании — вернуть в `draft: true`).

## Правки и задачи

Кнопки «Изменить» и админ-панель бота (`/panel` → «Задача для Claude») создают GitHub-issue
с меткой `claude-task` в `petrosyanbig8-crypto/biznes_na_ii`. Ежечасная задача Claude (9:00–23:00, в :07)
их разбирает, отвечает Гвидону в Telegram и закрывает issue. Отдельный `ops/inbox.json` не нужен —
панель уже работает через issues (см. README бота, раздел «Панель и задачи для Claude»).

## Статус

После публикаций обновляй `ops/status.json` — его удобно смотреть одним файлом.
